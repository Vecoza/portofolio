## Getting Started

### Prerequisites

- Node.js (v18+)
- Angular CLI

```bash
npm install -g @angular/cli
```

### Installation

```bash
# Clone the repository
git clone https://github.com/Vecoza/portofolio.git
cd portofolio

# Install dependencies
npm install
```

### Running Locally

```bash
ng serve
```

App will be available at `http://localhost:4200`

### Build

```bash
ng build
```

Build output goes to `dist/portfolio/`

---

## Deployment

This project is deployed via **Firebase Hosting**.

```bash
# Build the project
ng build

# Deploy to Firebase
firebase deploy
```
